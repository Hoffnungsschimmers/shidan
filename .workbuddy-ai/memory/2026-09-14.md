## 第九轮：v0.3.5 —— 无障碍细化

这一版没有新功能，修的都是「视觉上有、非视觉用户拿不到」的信息缺失。
V0.3 的三个既定候选（年度回顾 / 无障碍 / 分享接入时间线）里，先做无障碍。

### 1. 加载中的按钮对屏幕阅读器是一片空白

`MiuixButton` 在 `loading = true` 时把标签**替换**成转圈，
于是按钮的语义内容变成空的 —— 读不出是什么按钮，也不知道正在处理。

修法：语义整体重写。

```kotlin
.clearAndSetSemantics {
    contentDescription = label
    role = Role.Button
    if (loading) stateDescription = "处理中"
    if (active) onClick(label = label) { onClick(); true } else disabled()
}
```

**关键坑**：`clearAndSetSemantics` 会连 `clickable` 的语义一起清掉。
不显式补回 `role` 与 `onClick`（或 `disabled`），按钮会对无障碍服务**直接消失**。
这是「修一个无障碍问题引入另一个」的典型，必须成对写。

### 2. 分段控件读不出哪个被选中

`MiuixSegmented` 用的是 `clickable(role = Role.Tab)` —— 视觉上有滑动的白色指示块，
但选中状态**没有进入语义树**。

修法：容器 `selectableGroup()` + 选项 `selectable(selected, role = Role.Tab)`。
两者**必须配对**，只写一个不会播报「已选中」。
指示块用 `clearAndSetSemantics {}` 排除（纯装饰，否则多读一个空元素）。

### 3. 图表对屏幕阅读器完全不可见

柱状图结构上全是 `Box` 与空 `Text`。改为整体描述：
`「3月 5 次，4月 2 次，…」`。逐柱朗读 12 个数字既冗长，又还原不出趋势。

「去得最多的店」整行拼成一句 `「第 1 名 老王面馆，去过 3 次」` ——
默认逐子元素朗读会把「1」「老王面馆」「3 次」拆成三段互不相关的信息。
这里同样要补回 `Role.Button` 与 `onClick`。

### 4. 其它

- 概览数字带滚动动画，屏幕阅读器可能读到动画中间值 → 锁定最终值播报。
- 照片查看器的 `3 / 9` 会被读成「三 斜杠 九」→ 改为「第 3 张，共 9 张」。
- 比例条、指示块等纯装饰元素全部排除出语义树。

### 5. 大字体

分段控件高度原为固定 46dp，系统字体最大档会裁字。改为**按文字行高反推最小高度**：

```kotlin
val textHeight = with(LocalDensity.current) { labelLineHeight.toDp() }
val segmentHeight = maxOf(SEGMENT_HEIGHT, textHeight + SEGMENT_INSET * 2 + 10.dp)
```

算了一下各档：fontScale 1.0 → 38dp、1.3 → 44dp，都小于 46dp，
所以**常规情况下高度完全不变**，只有 2.0 才撑到 58dp。这个「默认外观不变」
是刻意的 —— 无障碍修复不该顺手改掉所有人看到的样子。

`MiuixButton` 的 `height(54.dp)` 同样改为 `heightIn(min = 54.dp)`：
54dp 是**最小**高度而非固定高度。

### 6. 评估后没做的

  真要让导航栏长高，`MainContentBottomPadding`（内容区底部留白，104dp 常量）
  也得跟着动态化，牵动三个标签页的 padding。收益小、改动面大，先不做。
- **卡片语义合并**：`MiuixCard` 加 `mergeDescendants` 会让卡片内的照片缩略图、
  编辑/删除按钮对 TalkBack 失效。凡是卡片内有可交互子元素就不能合并，
  而 `MiuixCard` 是通用组件、无法自行判断，因此不加。
